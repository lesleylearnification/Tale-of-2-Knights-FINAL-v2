# A Tale of Two Knights — FINAL v4

This package preserves the polished FINAL-v2 artwork and adds:

- The Then Test before the experience
- Working location selection
- Working Continue and Back controls
- Training Yard decision and feedback
- Four-field journal reflection
- Chronicle screen
- The Then Test repeated after the experience
- Before/after comparison
- Updated Memory Book summary
- Browser progress saving with localStorage

## Upload

Replace the current repository files with:

- index.html
- styles.css
- game.js
- assets/

Commit the files, then hard-refresh with Ctrl+Shift+R.
